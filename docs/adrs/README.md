New ADRs use stable numeric identifiers and record context, decision,
alternatives, rationale, consequences, status, and implementation evidence.
An accepted but unimplemented decision must say so explicitly and must not be
used as current capability or support evidence. Current technical facts remain
owned by code, schemas, registries, configuration definitions, protocols, and
the formal documents indexed by `docs/README.md`.
